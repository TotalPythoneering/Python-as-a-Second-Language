covering the unique things Python 3 can do, and less time on beginner
programming topics. (\*) From using Python 3's core modules,
collections, objects, and built-in functions PSL-1100 students will
master such advanced concepts as lambdas, sorting, enumerations,
slicing, f-strings, comprehensions, reporting, testing ... all in under
2 hours!

By creating first class functions, command-lines as well enjoying many
new cross-platform DevOps Demonstrations, in Python 1100 students will
also enjoy discovering how to get the most out of modern Python as
rapidly, as well as responsibly, as possible.

with an on-line resource dedicated to keeping track of the latest

## Lessons

01: Why 'P.S.L'?

Just how much Python do we need to know? To tell the truth the honest
answer depends upon what we are planning to do with it - as well as what
we've coded before.

02: The Python 'Phenom

Hiding in plain sight - perhaps - yet the truth remains that
perseverance is possibly why Python has become the most popular and
productive programming languages on the planet.

03: The Interpreter

From the T.U.I to the G.U.I Python's interpreter is usually the same for
every programming session, and the key Python 3 operations works the
same on just about every modern operating environment.

04: The R.E.P.L

The absolute basics, tabs and spaces are impossibly important in Python.
So too is understanding how Python's \[R\]ead, \[E\]valuate, \[P\]rint,
and \[L\]oop functions work together.

05: Data Values & Types

Data and mathematical expression evaluations make any R.E.P.L session
extremely handy right out of the box.

06: How Scripting Works

Just-in time program compilation is why Python is so much faster after
being run once. Let's get started by defining our own functions,
formats, and parameters.

07: Ranges & Ternary Operations

Python has many unique ways to assign values, define functions, process
ranges, enumerate values, and do some pretty interesting 'pythonic'
things.

08: Collections & Representations

Defining & processing data without reading a file is a strong reason why
many consider Python the go-to data processor of choice.

09: Data in Collections

Rock-solid data collection types in modern Python span 'mutable,'
'immutable,' sets, dictionaries, lists, strings, and 'tuples' - also
known as immutable collections.

10: Operations Included

Far from static, Python has many built-in operations that are always
available. Let's take a closer look at the two values (!) that we must
use when using enumerate() - let's go with that flow?

11: Reporting Basics

Understanding how 'modulus' works is the first step in creating
meaningful reports. So too is managing Exceptions ~ or ~ keeping
programs running even when things go wrong.

12: User Input

Whenever we’re working with people we all know that 'exceptional' things
can happen?

13: Complete Program

With version 10 Python's multi-block statements have expanded - but
there is much old, and presently few new 'match case' caveats to master.

14: Collection Patterns

Common usages and predictable patterns are very arguably the super-power
of Python. So let's take a moment to see how mastering one collection
helps us master so many - and so much - more.

15: The Power of 'Set'

Yes, Python's set() has member functions like every other - by set's
mathematical operators are were this collection truly crosses into the
legendary programming realm.

16: Comprehensions

Nothing screams 'Python mastery' louder than writing 'comprehensions' -
using list, set, dictionary, and other selection operations if you've
ever written any other code you'll be impressed as well.

17: Locking Collections

From 'freezing' sets to limiting what others might add to our
collections the ability to limit data types is an edge case worth
knowing about.

18: List Comprehensions

The best way to understand comprehensions is to copy an example first,
then customize it later.

19: Generating Comprehensions

Like 'frozenset' passing a list comprehension to the named tuple() class
will also create an immutable result.

20: Dictionary Formatting & Reporting

Like match / case formatting data in Python has evolved over the years.
Dictionaries are a great way tag the values that we'll often like to see
formatted.

21: Formatting & Dict Delta

For a brief moment Python's dictionaries went a tad eccentric - so
there's a reason why OrderedDict became all the fad in Python 3.

22: Lambdas & Data Collections

From collecting integers, strings, and booleans one great way to build
your own re-use is to practice converting user input into data and
collection types.

23: Sorting, Symbols & Operations

Python can teach us a lot, so let's take sometime to challenge ourselves
to exercise the help() system for these topics?

24: Great Escapes

From operators to operator precedence, taking deeper-dives into the help
system is the next self-learning Python power-up.

25: Unicode Challenge

From the T.U.I to the G.U.I the biggest change in Python 3 has been the
default use of Unicode characters. From UTF-8 files to glyph-enabled
screens when we're using integers instead of characters the sheer scope
of the new possibilities is truly impressive.

26: Challenge Solution

Sharing the code to the chess challenger.

27: Review Questions

Short, sweet, and tidy I believe that the real power of modern Python is
being able to use the help system to continue our Pythoneering
education.
